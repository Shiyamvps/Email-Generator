
# AI Email Generator

## Project Overview
An AI-powered email generator built using Python,
Streamlit, Prompt Engineering and OpenAI API.

## Features
- Generate professional emails
- Select email tone
- Select recipient type
- Generate subject and email body
- Validate empty inputs

## Technologies Used
- Python
- Streamlit
- OpenAI API
- Prompt Engineering

## Installation

pip install -r requirements.txt

## Run Application

streamlit run app.py
